# UK Property Market Analysis

## Project Overview

This project explores UK residential property prices, housing affordability and property market trends using publicly available data.

The aim is to apply practical data analysis techniques to questions relevant to the UK housing market and property investment.

## Research Questions

- How have residential property prices changed over time?
- How do prices differ between locations and property types?
- How do house prices compare with local earnings?
- What can historical price trends tell us about property markets, and what are the limitations of the analysis?

## Tools and Technologies

- Python
- pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook / Google Colab
- SQL (planned)
- GitHub for version control and project documentation

## Data Sources

The project will use publicly available UK housing and economic data. Sources, data coverage and any limitations will be documented as the analysis develops.

## Project Status

In progress — data collection and exploratory analysis have not yet been completed.

## Planned Outputs

- Data cleaning and exploratory data analysis
- Charts showing price trends and differences by location and property type
- An affordability analysis using suitable local earnings data
- Findings, limitations and practical conclusions

## Limitations

Historical price patterns do not guarantee future returns. Any affordability or investment indicators will depend on the coverage, definitions and quality of the underlying data.
